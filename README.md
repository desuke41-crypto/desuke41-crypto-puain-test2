# desuke41 読みもの案内所

`desuke41.hateblo.jp` の公開記事を紹介する、レスポンシブな人気記事ページです。

## 起動方法

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。

## 記事データについて

ページを開くと、はてなブログの公開フィードから実際の記事タイトル、概要、カテゴリ、公開日、記事URLを取得します。架空の記事や別テーマのコンテンツは表示しません。

## 天気データについて

東京（日本）、ソウル（韓国）、台北（台湾）の現在の気温・天気・体感温度・風速と、その日の最高気温・最低気温・降水確率を [Open-Meteo](https://open-meteo.com/) から取得します。取得できない場合は、古い情報を表示せずエラーメッセージを表示します。

各都市の「ブログ用リンクをコピー」を押すと、「韓国・ソウルの天気予報」のような文字付きリンクをコピーできます。はてなブログの編集画面へそのまま貼り付けられるリッチテキストと、Markdown形式の両方に対応しています。

### 人気記事の更新

はてなブログの公開APIおよびAtomフィードには、記事ごとのアクセス数やアクセス順ランキングは含まれません。そのため、次の優先順位で表示します。

1. `popular-posts.json` にアクセス解析結果があれば、そのPV順位
2. アクセス解析結果がなければ、公開APIから取得したはてなブックマーク数順
3. ブックマークAPIも利用できなければ、新着順。ただし「人気記事」とは表示せず「新着記事（ランキングなし）」と明記

各ランキング行には `1,234 PV`、`12 users`、`PVデータ利用不可` のいずれかを表示し、順位の根拠が分かるようにしています。

管理画面の「アクセス解析」またはブログに設置した公式の「注目記事」モジュールで順番を確認し、`popular-posts.json` の `articles` に上位記事を順番どおり記入してください。各項目では `title`、`url`、`category`、`date`、`summary`、`pv` を使用できます。PVを公開したくない場合は `pv` を省略すると「アクセス解析順位」と表示します。

```json
{
  "updatedAt": "2026-08-30",
  "source": "Hatena Blog access analytics / Featured Posts module",
  "articles": [
    {
      "title": "実際の記事タイトル",
      "url": "https://desuke41.hateblo.jp/entry/example",
      "category": "カテゴリ",
      "date": "2026/8/30",
      "summary": "記事の説明",
      "pv": 1234
    }
  ]
}
```

## 主な機能

- 日本・韓国・台湾の3都市の天気表示
- 人気記事トップ5のランキング表示
- 公開フィードと連動した新着記事表示
- アクセス解析または公式「注目記事」に基づく人気順表示
- タイトル・概要・カテゴリのキーワード検索
- PC・タブレット・スマートフォン対応
- キーボード操作や視覚的なフォーカスを考慮したHTML構造
