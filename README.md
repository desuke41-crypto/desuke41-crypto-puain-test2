# desuke41 読みもの案内所

`desuke41.hateblo.jp` の公開記事を紹介する、レスポンシブな人気記事ページです。

## 起動方法

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。

## 記事データについて

ページを開くと、はてなブログの公開フィードから実際の記事タイトル、概要、カテゴリ、公開日、記事URLを取得します。人気記事は、取得した記事のはてなブックマーク数を参照して並べます。架空の記事や別テーマのコンテンツは表示しません。

## 主な機能

- 人気記事トップ5のランキング表示
- 公開フィードと連動した新着記事表示
- はてなブックマーク数に基づく人気順表示
- タイトル・概要・カテゴリのキーワード検索
- PC・タブレット・スマートフォン対応
- キーボード操作や視覚的なフォーカスを考慮したHTML構造
