# desuke41 読みもの案内所

はてなブログの人気記事をランキングやテーマ別に紹介する、レスポンシブな静的サイトです。

## 起動方法

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。

## 記事を更新する

`script.js` 冒頭の `articles` 配列を編集すると、ランキングと記事一覧の両方に反映されます。各記事にはタイトル、カテゴリ、日付、読了時間、概要を設定できます。リンク先は同ファイルの `blogUrl` で変更できます。

## 主な機能

- 人気記事トップ5のランキング表示
- カテゴリフィルターとキーワード検索
- PC・タブレット・スマートフォン対応
- キーボード操作や視覚的なフォーカスを考慮したHTML構造
