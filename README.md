# desuke41 読みもの案内所

`desuke41.hateblo.jp` の公開記事を紹介する、レスポンシブな人気記事ページです。

## 起動方法

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。

## 記事データについて

ページを開くと、はてなブログの公開フィードから実際の記事タイトル、概要、カテゴリ、公開日、記事URLを取得します。架空の記事や別テーマのコンテンツは表示しません。

### 人気記事の更新

はてなブログの公開APIおよびAtomフィードには、記事ごとのアクセス数やアクセス順ランキングは含まれません。アクセス数と同じ意味ではない「はてなブックマーク数」を代用することもやめました。

管理画面の「アクセス解析」またはブログに設置した公式の「注目記事」モジュールで順番を確認し、`popular-posts.json` の `articles` に上位記事を順番どおり記入してください。各項目では `title`、`url`、`category`、`date`、`summary` を使用できます。アクセス数そのものを公開ページへ載せる必要はありません。

```json
{
  "updatedAt": "2026-08-30",
  "source": "Hatena Blog access analytics / Featured Posts module",
  "articles": [
    {
      "title": "実際の記事タイトル",
      "url": "https://desuke41.hateblo.jp/entry/example",
      "category": "カテゴリ",
      "date": "2026/8/30",
      "summary": "記事の説明"
    }
  ]
}
```

## 主な機能

- 人気記事トップ5のランキング表示
- 公開フィードと連動した新着記事表示
- アクセス解析または公式「注目記事」に基づく人気順表示
- タイトル・概要・カテゴリのキーワード検索
- PC・タブレット・スマートフォン対応
- キーボード操作や視覚的なフォーカスを考慮したHTML構造
