# SEKAI WEATHER

世界6都市の現在の天気と3日間予報を表示する、シンプルな天気ダッシュボードです。

## 利用している天気サービス

[Open-Meteo](https://open-meteo.com/) の無料天気予報APIを利用しています。APIキーやアカウント登録は必要ありません。

ページを開くと、ブラウザのJavaScriptがOpen-Meteoへ直接アクセスし、最新データで各カードを更新します。取得できない場合は、最初からHTMLに書かれているサンプル値を残し、画面上にエラーメッセージを表示します。

## 初心者向け：動かし方

特別な設定ファイルやパスワードは不要です。ターミナルでこのフォルダーへ移動し、次のコマンドを実行してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで <http://localhost:8000> を開きます。終了するときは、ターミナルで `Ctrl+C` を押します。

> 天気を取得するにはインターネット接続が必要です。会社や学校のネットワークで外部APIが制限されている場合は、取得に失敗することがあります。

## 表示する都市を変更する方法

`index.html` の各 `.weather-card` にある、次の2つの値を変更します。

- `data-latitude`: 都市の緯度
- `data-longitude`: 都市の経度

都市名、国名、地域名も同じカード内の文字を書き換えてください。APIの呼び出し処理自体を変更する必要はありません。

## 主なファイル

- `index.html`: 都市カードやボタンなど、画面の内容
- `styles.css`: 色、配置、スマートフォン表示など、画面の見た目
- `script.js`: APIからの取得、天気表示、再取得、摂氏・華氏の切り替え
