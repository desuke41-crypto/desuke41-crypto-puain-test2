# まちのカーサポート チラシ

オイル交換と、待ち時間に利用できるスマホ操作説明サービスを案内するレスポンシブなWebチラシです。

## 起動方法

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。

## 掲載内容

- オイル交換の価格とサービスの特長
- 15分500円（税込）のスマホ操作説明サービス
- 説明できる操作の例と、対象外サービスについての注意書き
- 電話予約への導線、営業時間、店舗情報
- PC・スマートフォン・印刷に対応したレイアウト

公開前に、電話番号・住所・営業時間・料金を実際の店舗情報へ差し替えてください。
